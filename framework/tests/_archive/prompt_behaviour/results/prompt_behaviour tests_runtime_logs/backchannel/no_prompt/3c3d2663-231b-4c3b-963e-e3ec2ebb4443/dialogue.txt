Well, basically, this is Landseer's take on "Orientalism," which was a bit of a fashion trend back in the day. It's less about a specific story and more about showing off a luxurious, exotic scene. He's really using the animals to create a sense of hierarchy—if you look up, the animals actually get more "intelligent," going from the mare and foal up to the monkeys.
