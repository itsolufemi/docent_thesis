Well, basically, this painting is all about the Victorian fascination with the "Exotic East"—what we call Orientalism. Landseer is using the animals to create a bit of a hierarchy; if you look closely, the more intelligent the animal is, the higher up in the frame it's placed, moving from the horses up to the monkeys. It's actually a pretty rare move for Landseer, who was usually the go-to guy for royal portraits and dogs.
